# ✨ LumiMenu

## Carta Digital Premium para Restaurantes

LumiMenu es una experiencia de menú digital diseñada para restaurantes que buscan transformar una simple carta en una experiencia gastronómica moderna, elegante y rápida.

La idea nace de algo cotidiano: escanear un código QR en un restaurante y acceder a un menú digital. LumiMenu busca mejorar esa experiencia combinando diseño premium, animaciones suaves y una navegación intuitiva.

# 🚀 Características

## 🍽️ Carta interactiva

- Navegación por categorías.
- Visualización rápida de platos.
- Información detallada mediante modal.
- Descripciones, precios y etiquetas gastronómicas.

## ⭐ Experiencia Premium

- Pantalla de bienvenida animada.
- Diseño inspirado en restaurantes de alta gama.
- Animaciones suaves.
- Interfaz minimalista.

## 🏷️ Información gastronómica

Cada plato puede mostrar:

- ⭐ Recomendación del chef.
- 🥬 Vegetariano.
- 🌱 Vegano.
- ✓ Sin TACC.
- 🌶 Picante.
